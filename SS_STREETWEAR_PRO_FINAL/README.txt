S&S STREETWEAR - LOGIN CORREGIDO

1. Instala Python 3 si no lo tienes.
2. Ejecuta INICIAR_S_S.bat desde la carpeta principal.
3. Se abrirá http://127.0.0.1:5000/user/
4. Pulsa el icono de usuario y usa:
   Correo: admin@ssstreetwear.com
   Contraseña: Admin123!
5. Entrar te llevará a http://127.0.0.1:5000/admin/

IMPORTANTE: NO abras user/index.html con doble clic (file://). Usa INICIAR_S_S.bat para que Flask sirva la tienda y la API.

Si Windows muestra una consola negra del servidor, déjala abierta mientras uses la página.
