# S&S STREETWEAR

Aplicación web de tienda urbana con Flask, SQLite, cuentas de usuario, panel de administración, catálogo, pedidos, clientes y publicación en Render.

## Inicio rápido

```bash
cd backend
python -m venv .venv
# Windows
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

Abrir: `http://127.0.0.1:5000/`

La documentación completa para publicar está en `README_INTERNET.txt`.
